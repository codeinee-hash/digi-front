# DiGi GeoPlatform — Управление картографическими слоями GIS

Интерфейс управления геопространственными слоями с интерактивной картой (температура поверхности, векторное поле ветра, солнечная инсоляция).

## Стек технологий

- **Фреймворк**: React 19, TypeScript (строгий режим, без `any`)
- **Стейт-менеджер**: `vedro` (изоляция рендеров через атомарные селекторы)
- **Стилизация**: Tailwind CSS v4, Base UI (shadcn/ui), Lucide Icons
- **Сборка и линтинг**: Vite, ESLint (Flat Config), Prettier, Husky, lint-staged

## Архитектура (Simplified 3-Layer FSD)

```
src/
├── app/                  # Инициализация, провайдеры (Vedro, Tooltip), корневой лейаут
│   ├── app.tsx
│   ├── providers.tsx
│   └── main.tsx
├── features/             # Бизнес-модули
│   ├── layer-management/ # Стор Vedro, хуки действий, список слоев, карточка слоя, фильтры
│   └── map-viewer/       # Canvas-карта, наложение слоев с учетом opacity, легенда
└── shared/               # Переиспользуемые ресурсы
    ├── api/              # Mock API геоданных с поддержкой AbortSignal и эмуляцией сбоев
    ├── lib/              # LayerAbortManager (отмена запросов), utils
    ├── model/            # Типы (Discriminated Unions), слои по умолчанию, генератор 100+ слоев
    └── ui/               # Базовые UI-компоненты (button, slider, switch, badge, card, tooltip, input)
```

## Реализованная функциональность

1. **Слои карты**:
   - Температура поверхности (`TEMP_SURFACE_2M`)
   - Векторное поле ветра (`WIND_VECTORS_10M`)
   - Солнечная инсоляция (`SOLAR_GHI_IRRADIANCE`)
2. **Управление слоем**:
   - Включение / выключение с запросом к mock API
   - Регулировка прозрачности (0–100%) через слайдер
   - Статусы: `idle`, `loading`, `success`, `error`
   - Повторная загрузка (`Retry`) при ошибке
   - Тумблер эмуляции сбоев сети для проверки обработки ошибок
3. **Производительность и стейт (`vedro`)**:
   - Нормализованное состояние (`layers: Record<string, LayerState>`)
   - Гранулярная подписка: обновление одного слоя не вызывает рендер соседних компонентов
   - Монитор `renders: N` в карточках для визуального контроля
4. **Защита от Race Conditions**:
   - `LayerAbortManager` на базе `AbortController`: при быстром переключении тумблера или повторном запросе незавершенный сетевой вызов немедленно отменяется
   - Проверка `requestId` исключает перезапись состояния устаревшими ответами
5. **Масштабируемость (100+ слоев)**:
   - Переключатель: «3 слоя (ТЗ)» / «100+ слоёв»
   - Поиск по названию/коду и фильтрация по категориям
   - Массовое включение и сброс слоев
6. **Интерактивная карта (Canvas)**:
   - Географическая привязка (Бишкек, Чуйский регион, WGS 84)
   - Отрисовка рельефа, теплового градиента, векторных потоков ветра и радиации
   - Применение прозрачности (`opacity`) в реальном времени
   - Инспектор координат курсора и динамическая легенда

## Контроль качества кода (Git Hooks)

- **Pre-commit (`lint-staged`)**:
  - Автоформатирование через Prettier (`singleQuote: true`, `semi: false`)
  - ESLint: строгий запрет `console.log` (`no-console`) и неиспользуемых переменных (`@typescript-eslint/no-unused-vars`)
  - Коммит блокируется при наличии ошибок
- **Pre-push**:
  - Запуск `npm run build` (`tsc -b && vite build`) перед отправкой ветки на remote
